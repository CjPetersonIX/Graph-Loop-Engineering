### Overview

This repository contains the white paper:

**Graph and Loop Engineering as the Actual Standard: Why One-Shot Prompting Was Never the Real Discipline**

The paper argues that the real engineering discipline for multi-agent systems is the deliberate design of graphs (structure, relationships, authority) and loops (self-correction, status, handoff, recovery). One-shot prompt engineering was never the foundation of serious long-running systems.
